# Copy Embed Button (Deliverable A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Copy Embed" control to `build-sheet.html` that copies forum BBCode referencing the (not-yet-built) embed image server.

**Architecture:** Pure client change in the static `ts-builder` app. A new read-only textarea holds a `[URL=buildUrl][IMG]embedUrl[/IMG][/URL]` string built in `generateBuildCodes()`. Copy reuses the existing `.copy-button` handler. The embed image URL derives from the same compact build code already used for the Build URL; the server that serves that image is Deliverable B (separate repo) and is not required for this deliverable to ship.

**Tech Stack:** Vanilla JS/HTML, no build system, no test runner (per `CLAUDE.md`). Verification: a Node+jsdom harness that drives the *real* encoder, plus a manual browser check.

## Global Constraints

- No new dependencies, no build tooling — plain JS/HTML only.
- Commits: local git account; never add "Generated by Claude Code" / "Co-authored-by" trailers.
- Clipboard payload format (verbatim from spec): `[URL={buildUrl}][IMG]{embedUrl}[/IMG][/URL]`.
- `embedUrl` format: `{EMBED_BASE}/embed/{encodeURIComponent(code)}.webp`.
- `code` = the `encodedBuild` segment after `#import.` in the Build URL.
- Image format is WebP (`.webp` suffix in the URL).
- `EMBED_BASE` is a single client-side constant; final domain is deferred — ship with placeholder `https://embed.terrarp.com`.
- Reference spec: `docs/superpowers/specs/2026-07-03-build-embed-image-design.md`.

- [ ] **Step 1: Write the failing test (Node + jsdom harness)**

Create `C:/Users/warwo/AppData/Local/Temp/claude/D--Kenny-Project-Terrasphere-ts-builder/60bb2dbd-d65b-4215-96d6-d86b2cca891c/scratchpad/verify-embed.js`. It loads the real `build-encoder.js` + data files (window-shimmed), generates a real code from a crafted state, then asserts the exact BBCode assembly logic that `generateBuildCodes` will use:

```js
const fs = require("fs");
const vm = require("vm");
const { JSDOM } = require("jsdom");
const ROOT = "D:/Kenny/Project/Terrasphere/ts-builder";

const dom = new JSDOM("<!doctype html><body></body>", { url: "https://terrarp.com/build/build-sheet.html" });
const sandbox = { window: dom.window, document: dom.window.document, console, btoa: dom.window.btoa, atob: dom.window.atob };
sandbox.globalThis = sandbox;
vm.createContext(sandbox);
for (const f of ["resource/safecharacters.js","resource/masteries.js","resource/expertise.js","resource/actions.js","shared/build-encoder.js"]) {
  vm.runInContext(fs.readFileSync(`${ROOT}/${f}`, "utf8"), sandbox);
}
const BuildEncoder = sandbox.window.BuildEncoder || sandbox.BuildEncoder;

// Replicate ONLY the new assembly (this is the logic under test)
const EMBED_BASE = "https://embed.terrarp.com";
function buildEmbedBBCode(buildURL) {
  const code = buildURL.split("#import.")[1] || "";
  if (!code) return "";
  const embedUrl = `${EMBED_BASE}/embed/${encodeURIComponent(code)}.webp`;
  return `[URL=${buildURL}][IMG]${embedUrl}[/IMG][/URL]`;
}

const state = {
  chosenMasteries: ["aeromancy", "guard-arts"],
  chosenMasteriesRanks: [7, 5],
  chosenExpertise: [], chosenExpertiseRanks: [],
  armorType: null, armorRank: 0, accessoryType: null, accessoryRank: 0,
  weaponRank: 5, chosenActions: ["heal"], characterName: "T", characterRace: "", characterTitle: "", note: "", ng: 0,
};

let pass = 0, fail = 0;
const ok = (n, c) => { (c ? pass++ : fail++); console.log((c ? "PASS " : "FAIL ") + n); };

const buildURL = BuildEncoder.generateCompactBuildCode(state);
const bb = buildEmbedBBCode(buildURL);
const code = buildURL.split("#import.")[1];

ok("buildURL contains #import.", buildURL.includes("#import."));
ok("BBCode wraps URL+IMG", /^\[URL=.+\]\[IMG\].+\[\/IMG\]\[\/URL\]$/.test(bb));
ok("IMG points at EMBED_BASE /embed/..webp", bb.includes(`[IMG]${EMBED_BASE}/embed/`) && bb.includes(".webp[/IMG]"));
ok("code is URL-encoded in the img src (no raw + / =)", (() => {
  const src = bb.split("[IMG]")[1].split("[/IMG]")[0];
  const enc = src.slice(`${EMBED_BASE}/embed/`.length, -".webp".length);
  return enc === encodeURIComponent(code);
})());
ok("empty code yields empty BBCode", buildEmbedBBCode("https://x/build/build-sheet.html") === "");

console.log(`\n${pass} passed, ${fail} failed`);
process.exit(fail ? 1 : 0);
```
